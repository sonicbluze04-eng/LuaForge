# 🛠️ LuaForge.py
### *The Ultimate Universal Manifest & DirectLua Configuration Hub*

LuaForge.py is a high-performance desktop automation utility built entirely in Python using a lightweight multi-threaded architecture. It is designed to effortlessly manage, analyze, and configure offline game archives by bypassing platform layout locks and automating asset verification scripts.

## 🔥 Key Engineering Capabilities

* **📦 Local Directory Analytics:** Recursively crawls and scans any local game backup directory (like *FlatOut 2*), running high-speed chunk-buffered parsing to index file structures and total bytes without locking up your system's memory frames.
* **🌀 Dual-Engine Code Generation:** Instantly outputs structurally accurate Steam `appmanifest.acf` deployment blocks (forcing the game client to see files as 100% installed and updated) and custom script profiles.
* **📡 Authentic DirectLua Injection Mapping:** Built specifically to auto-compile the complex relational syntax required by DirectLua database models. It outputs precise `addappid()` and `-- setManifestid()` function chains, mapping custom cryptographic hashes and depot identifiers natively.
* **⚡ Absolute Manual Force-Generator:** Features a bulletproof manual override interface layer. If an obscure, unlisted, or modded game doesn’t appear in online databases, you can manually type its name and AppID to forcefully inject perfect layout files anywhere on your disk—giving it 100% compatibility with every game in existence.
* **🖥️ High-Visibility Dark Canvas:** Features a customized dark-mode graphic user interface built on forced high-contrast styling definitions. This ensures text entries, matrix search fields, and terminal monitoring logs remain bright, sharp, and perfectly readable.

## 🚀 Installation & Compilation Deployment

To execute or compile the codebase locally on your machine, ensure you have **Python 3** installed and execute the following routines:

1. Clone or download `LuaForge.py` directly into a folder on your Desktop.
2. Open your system Command Prompt (cmd) or terminal inside that folder.
3. To package the single-file script into a standalone, single-click executable utility with zero background command windows popping open, run the following compiler command:
   ```bash
   pyinstaller --onefile --windowed LuaForge.py
   ```
4. Access your finished app bundle natively inside the newly generated `dist/` directory!

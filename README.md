# 🛠️ LuaForge.py
### *The Ultimate Universal Manifest & DirectLua Configuration Hub*

LuaForge is a high-performance desktop automation utility designed to effortlessly manage, analyze, and configure offline game archives by bypassing platform layout locks and automating asset verification scripts. 

**This is a standalone desktop application. NO Python installation and NO command prompt setup are required to run it!**

## 🔥 Key Engineering Capabilities

* **📦 Local Directory Analytics:** Recursively crawls and scans any local game backup directory (like *FlatOut 2*), running high-speed chunk-buffered parsing to index file architectures and total bytes without locking up your system's memory frames.
* **🌀 Dual-Engine Code Generation:** Instantly outputs structurally accurate Steam `appmanifest.acf` deployment blocks (forcing the game client to see files as 100% installed and updated) and custom script profiles.
* **📡 Authentic DirectLua Injection Mapping:** Built specifically to auto-compile the complex relational syntax required by DirectLua database models. It outputs precise `addappid()` and `-- setManifestid()` function chains, mapping custom cryptographic hashes and depot identifiers natively.
* **⚡ Absolute Manual Force-Generator:** Features a bulletproof manual override interface layer. If an obscure, unlisted, or modded game doesn’t appear in online databases, you can manually type its name and AppID to forcefully inject perfect layout files anywhere on your disk—giving it 100% compatibility with every game in existence.
* **🖥️ High-Visibility Dark Canvas:** Features a customized dark-mode graphic user interface built on forced high-contrast styling definitions. This ensures text entries, matrix search fields, and terminal monitoring logs remain bright, sharp, and perfectly readable.
